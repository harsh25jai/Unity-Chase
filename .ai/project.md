# Chase: Project Mission & Tech Stack

## Business Mission
"Chase" is a Unity-based racing and police pursuit video game. The core gameplay loop revolves around dynamic vehicle traversal, high-stakes police escalations, and robust checkpoint-based progression in a multiplayer-capable world.

## Technology Stack
- **Engine:** Unity Engine (C#)
- **Render Pipeline:** Universal Render Pipeline (URP)
- **Networking/Multiplayer:** Netcode for GameObjects (`Unity.Netcode`) for session state and networking functionality.
- **Input:** Modern Unity Input System (`Unity.InputSystem`).
- **Performance/Compute:** Burst Compiler (`Unity.Burst`) & Unity Mathematics for high-performance physics/math calculations.
- **Cinematics & Cameras:** Cinemachine (`Unity.Cinemachine`) for dynamic camera takeover, pursuit perspectives, and cutscenes.
- **Visual Scripting:** Integrated Unity Visual Scripting for flow/state graphs.
